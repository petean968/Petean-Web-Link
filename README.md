Why I built this: I created this application to solve a common friction point: 
nobody wants to manually type a long Google Drive URL into a mobile browser just to see a portfolio.

The Solution: I designed a dedicated Android "Launcher" for my website. 
Instead of navigating through bookmarks or typing addresses, the user simply taps the app icon.

Instant Access: The app handles the redirection and opens my website in seconds.

Visual Feedback: I implemented a 5-second countdown timer on the screen, 
providing a smooth transition and letting the user know the portfolio is loading.
